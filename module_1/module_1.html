Probability Functions

  • Random variable \(x\)
  • Probability mass function \(p(x)\) if \(x\) is discrete

  • Probability density function \(f(x)\) if \(x\) is continuous.
  • \(f(x)\) describes a density, not a probability of an event.
  • Probability defined by some area under the curve, e.g. \[ p(x \leq 1)= \int_{-\infty}^1 f(x)dx \]

Expectation

  • Expected value of \(x\) (or mean) when discrete \[ \mathbb{E}(x) = \sum xp(x) \]
  mean(rbinom(10000, size = 10, prob = 0.25))

  • Sample mean \[ \mathbb{E}(x) = \frac{\sum x_i}{n} \]

Variance

  • Definition of variance is difference of squared expectation and expectation squared. \[ Var(x) = \mathbb{E}(x^2) - \mathbb{E}(x)^2. \]
  var(rgamma(10000, 1, 2))
[1] 0.2536976
  integrate(\(x){x^2*dgamma(x,1,2)}, lower=0, upper=Inf)$value - (1/2)^2
[1] 0.25
  • Sample variance \[ Var(x) = \frac{(\sum x_i - \bar{x})^2}{n-1} \]

Joint Density

  • Some sample \(\textbf{x}\), of size \(n\)
  • Assume \(x_i \sim N(\mu, \sigma)\) and all are independent.
  • Then the joint density is \[ f(\textbf{x}) = f(x_1, \ldots, f_n) = f(x_1)f(x_2) \cdots f(x_n) = \prod_{i=1}^n f(x_i) \]

Conditional Density

  • Some sample \(\textbf{x}\), of size \(n\)
  • Assume \(x_i|u \sim N(u + \mu, \sigma)\)
  • \(u \sim N(0, 1)\) is a random variable (e.g. random effect)
  • The \(x\) values are not independent! \[ f(\textbf{x}) \neq \prod_{i=1}^n f(x_i) \]
  • However, conditional on the value of \(u\), they are independent, \[ f(\textbf{x}|u) = \prod_{i=1}^n f(x_i|u) \]
  • Joint density can be written as \[ f(\textbf{x}) = \int f(\textbf{x},u)du = \int f(\textbf{x}|u)f(u)du \]

Likelihood

  • For some parameters \(\mathbf{\theta} = \{\mu, \sigma\}\)
  • Likelihood is the data joint density expressed in terms of the parameters, conditional on the data.
  • \(L(\mathbf{\theta} | \textbf{x}) = \prod_{i=1}^n f(x_i)\)
  • Maximum likelihood estimation – Find maximum values of parameters given the data.

Fitting a Likelihood in R

  • Maximum of likelihood is also maximum of log-likelihood
  • Maximization is the same as minimizing the negative.
  • Multiplying small numbers is bad…
  x <- rnorm(1000, 0, 5)
  fx <- dnorm(x, 0, 5)
  log(prod(fx))
[1] -Inf
  sum(log(fx))
[1] -3024.196
  • In general, we build the log-likelihood in R by summing over the log of each independent component of the likelihood.

\[ \log(L(\boldsymbol{\theta}|\mathbf{x}) = \sum \log(f(x_i)). \] - This is best done in R vectorized. Loops are generally slow, especially when nested. - In C++ loops are very fast.

  x <- rnorm(1000, 0, 5)
  ll_vec <- \(a){
    lfx <- dnorm(x, 0, 5, log = TRUE)
    ll <- sum(lfx)
    ll*a
  }
  ll_loop <- \(a){  
    ll <- 0
    for( i in 1:1000){
      ll <- ll + dnorm(x[i], 0, 5, log = TRUE)
    }
    ll*a
  }

  ## First taste of RTMB... :)
  ll_loopc <- RTMB::MakeTape(ll_loop, 1)
    
  microbenchmark::microbenchmark(
    vectorized = ll_vec(1),
    looped = ll_loop(1),
    looped_c = ll_loopc(1),
    times = 100
  )

Optimization in R

  • Gradient is the slope (derivative) in terms of the parameters
  • Gradient based optimization uses slope to find max/min by where the function is flat (gradient = 0)
  • Random start, evaluate objective function, use gradient to move to new value
  • Run until at maximum/minimum (where gradient is zero)
  • Examples are optim or nlminb
  • If gradient not provided, then finite differences are used.
set.seed(24)
x <- rnorm(100, 0.25, 2)
nll <- \(pars){
  mu <- pars[1]
  sigma <- exp(pars[2])
  -sum(dnorm(x, mu, sigma, log = TRUE))
}

optim(c(0,0), nll)

Optimization in R

  • What about more than one peak? (Multimodality)
  • Derivative is zero at more than one place
  • Want ‘global’ maximum
  • Random starting points and taking global max works
  • If likelihood looks this way there are likely other things wrong
  • In theory, as we get more data, the likelihood becomes more smooth and ‘peaky’
